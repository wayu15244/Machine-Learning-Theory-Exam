1. K-Nearest Neighbor (KNN) Classification

เป็นอัลกอริทึมจำแนกประเภทข้อมูลที่อาศัยหลักการพื้นฐาน "สิ่งที่คล้ายกันมักจะอยู่ใกล้กัน" (Things that are similar are close to each other) จัดอยู่ในกลุ่ม Lazy Learning เนื่องจากไม่มีขั้นตอนการเทรนสร้างแบบจำลองล่วงหน้า แต่จะจดจำชุดข้อมูลทั้งหมดไว้ แล้วจึงคำนวณระยะห่างเพื่อค้นหาเพื่อนบ้าน $K$ ตัวที่ใกล้ที่สุดเมื่อมีข้อมูลใหม่เข้ามา

กระบวนการทำงาน 6 ขั้นตอน

  1. Input New Sample (รับจุดทดสอบ $x$)
  2. Calculate Distance ($d(x, x_i)$ ทุกจุด)
  3. Sort Distance (เรียงน้อย $\rightarrow$ มาก)
  4. Select K Nearest (เลือก $K$ ตัวแรก)
  5. Majority Vote / Weighted Vote
  6. Prediction (กำหนดคลาสที่ชนะ)

การวัดระยะทาง (Distance Metrics)

Euclidean Distance:
\( d(x, y) = \sqrt{\sum_{i=1}^n (x_i - y_i)^2} \)
Manhattan Distance:
\( d(x, y) = \sum_{i=1}^n |x_i - y_i| \)

อิทธิพลของค่า K (K-Value Effect)

  • • K ขนาดเล็ก: ยืดหยุ่นสูง (Flexible) ขอบเขตซับซ้อน แต่ไวต่อสัญญาณรบกวนมาก (Noise Sensitive / Overfitting)
  • • K ขนาดใหญ่: เสถียร (Stable) ลดผลกระทบของ Noise แต่ขอบเขตอาจเรียบเกินไป (Underfitting)

2. K-Nearest Neighbor (KNN) Regression

เป็นอัลกอริทึมสำหรับพยากรณ์ ค่าตัวเลขต่อเนื่อง (Continuous Target Variable) เช่น ราคาบ้าน, ยอดขาย, หรือดัชนีหุ้น โดยอาศัยการหาเพื่อนบ้าน $K$ ตัวที่ใกล้ที่สุดในมิติของ Features แล้วนำค่า Target ของเพื่อนบ้านมาหา ค่าเฉลี่ย (Mean) หรือ ค่าเฉลี่ยถ่วงน้ำหนักตามระยะทาง (Distance-Weighted Average)

1. Simple KNN Regression (ค่าเฉลี่ยปกติ)

สไลด์หน้า 14-19
\( \hat{y} = \frac{1}{K} \sum_{i=1}^K y_i \)

ให้ความสำคัญกับเพื่อนบ้านทั้ง $K$ ตัวเท่ากันทั้งหมด เหมาะสำหรับข้อมูลที่มีการกระจายตัวสม่ำเสมอและไม่มี Outlier รบกวน

2. Weighted KNN Regression (ถ่วงน้ำหนักระยะทาง)

สไลด์หน้า 20-29
\( \hat{y} = \frac{\sum_{i=1}^K w_i \cdot y_i}{\sum_{i=1}^K w_i} \quad \text{โดย} \quad w_i = \frac{1}{d(x, x_i)^p + \epsilon} \)

เพื่อนบ้านที่อยู่ใกล้จุดทดสอบมากกว่าจะได้น้ำหนัก ($w_i$) สูงกว่า และมีอิทธิพลต่อผลทำนายมากกว่าเพื่อนบ้านที่อยู่ห่างออกไป (โดยทั่วไปกำหนด $p=2, \epsilon=10^{-5}$)

3. K-Means Clustering (การจัดกลุ่มข้อมูล)

เป็นอัลกอริทึมการเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning) ที่ไม่มีป้ายกำกับ (No Labels) มีเป้าหมายเพื่อ แบ่งข้อมูลออกเป็น $K$ กลุ่ม โดยอาศัยความใกล้เคียงของจุดข้อมูลกับ จุดศูนย์กลางของกลุ่ม (Centroid) เพื่อให้ข้อมูลภายในกลุ่มเดียวกันมีความคล้ายคลึงกันมากที่สุด และข้อมูลต่างกลุ่มกันมีความแตกต่างกันมากที่สุด

1
กำหนดค่า K

ระบุจำนวนกลุ่มที่ต้องการแบ่ง

2
กำหนด Initial Centroids

สุ่มหรือระบุตำแหน่งศูนย์กลางเริ่มต้น

3
Cluster Assignment

จัดจุดข้อมูลเข้าสังกัด Centroid ที่ใกล้ที่สุด

4
Update Centroid

หาค่าเฉลี่ย (\(\bar{x}, \bar{y}\)) เป็นจุดศูนย์กลางใหม่

5
Iteration & Stop

ทำซ้ำจน Centroid นิ่ง หรือครบรอบ

2 เกณฑ์ Cluster ดี vs Cluster ไม่ดี (สไลด์หน้า 12)

✓ Cluster ดี (Good Clustering): กลุ่มข้อมูลมีความชัดเจน แยกออกจากกัน ข้อมูลภายในกลุ่มเดียวกันเกาะกลุ่มหนาแน่น (High Intra-cluster similarity & Low Inter-cluster similarity)
✗ Cluster ไม่ดี (Poor Clustering): กลุ่มข้อมูลทับซ้อนกัน ข้อมูลกระจายกว้าง หรือจำนวนกลุ่ม $K$ ไม่สอดคล้องกับธรรมชาติของข้อมูล
