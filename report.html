1. K-Nearest Neighbor (KNN) Classification

1.1 ทฤษฎีและแนวคิดพื้นฐาน (Theoretical Concepts)

K-Nearest Neighbor (KNN) เป็นอัลกอริทึมการเรียนรู้แบบมีผู้สอน (Supervised Learning) ที่จัดอยู่ในกลุ่ม Instance-Based Learning (IBL) หรือ Lazy Learning มีลักษณะสำคัญคือ ไม่มีขั้นตอนการฝึกฝนเพื่อสร้างแบบจำลองทางคณิตศาสตร์ล่วงหน้า (No explicit model training) แต่จะเก็บรวบรวมตัวอย่างข้อมูลฝึก (Training Instances) ทั้งหมดไว้ในหน่วยความจำ เมื่อมีข้อมูลทดสอบใหม่เข้ามา (Query Point) จึงจะนำข้อมูลใหม่นั้นไปเปรียบเทียบความคล้ายคลึงกับข้อมูลทั้งหมด

แนวคิดรากฐานของ KNN อ้างอิงจากหลักการว่า "สิ่งที่คล้ายกันมักจะอยู่ใกล้กัน" (Things that are similar are close to each other) โดยนิยามความคล้ายคลึงผ่านฟังก์ชันวัดระยะห่าง (Distance Metric) ในปริภูมิข้อมูล

1.2 การวัดระยะทางและกระบวนการทำงาน 6 ขั้นตอน

ฟังก์ชันวัดระยะห่าง (Distance Metrics):
  • • Euclidean: \( d(x, y) = \sqrt{\sum_{i=1}^n (x_i - y_i)^2} \)
  • • Manhattan: \( d(x, y) = \sum_{i=1}^n |x_i - y_i| \)
  • • Minkowski: \( d(x, y) = \left(\sum_{i=1}^n |x_i - y_i|^p\right)^{1/p} \)
กระบวนการทำงาน 6 ขั้นตอน:
  1. Input New Sample (รับจุดทดสอบ \(x\))
  2. Calculate Distance (คำนวณ \(d(x, x_i)\))
  3. Sort Distance (เรียงลำดับน้อย \(\rightarrow\) มาก)
  4. Select K Nearest (เลือกเพื่อนบ้าน \(K\) ตัวแรก)
  5. Majority Vote (ลงคะแนนเสียงคลาส)
  6. Prediction (เลือกคลาสคะแนนสูงสุด)

1.3 ผลกระทบของการเลือกค่า K (Bias-Variance Tradeoff)

  • K ขนาดเล็ก (เช่น K=1): โมเดลมีความยืดหยุ่นสูง (Flexible) ขอบเขตการตัดสินใจปรับตัวตามข้อมูลได้ละเอียด แต่ข้อเสียคือไวต่อสัญญาณรบกวนมาก (Noise Sensitive) เกิดความแปรปรวนสูง (High Variance / Overfitting)
  • K ขนาดใหญ่: โมเดลมีความเสถียร (Stable) ลดผลกระทบของ Outlier ด้วยการใช้คะแนนเสียงจากหลายจุด แต่ข้อเสียคือเสี่ยงต่อ Underfitting ขอบเขตเรียบเกินไป และใช้เวลาคำนวณนาน
  • ข้อควรปฏิบัติ: ในปัญหาจำแนก 2 คลาส ควรเลือก \(K\) เป็นเลขคี่ เพื่อป้องกันคะแนนเสียงเท่ากัน (Tie)

2. K-Nearest Neighbor (KNN) Regression

2.1 ทฤษฎีและแนวคิดพื้นฐาน (Theoretical Concepts)

KNN Regression เป็นอัลกอริทึมสำหรับพยากรณ์ ค่าตัวเลขต่อเนื่อง (Continuous Target Variable) เช่น ราคาอสังหาริมทรัพย์, ยอดขาย, หรือราคาหุ้น โดยยังคงใช้หลักการค้นหาเพื่อนบ้านที่มีระยะห่างใกล้ที่สุด \(K\) ตัวในปริภูมิของคุณลักษณะ (Features) แต่เปลี่ยนขั้นตอนการสรุปผลจากการโหวตคลาส มาเป็นการหา ค่าเฉลี่ย (Mean) หรือ ค่าเฉลี่ยถ่วงน้ำหนักตามระยะทาง (Distance-Weighted Average)

2.2 รูปแบบการคำนวณผลลัพธ์ (Formulas)

1. Simple Average (ค่าเฉลี่ยปกติ):

เพื่อนบ้าน \(K\) ตัวมีน้ำหนักเท่ากันทั้งหมด:

\( \hat{y} = \frac{1}{K} \sum_{i=1}^K y_i \)
2. Distance-Weighted Average (ถ่วงน้ำหนัก):

เพื่อนบ้านที่ใกล้กว่ามีอิทธิพลต่อค่าทำนายมากกว่า:

\( \hat{y} = \frac{\sum_{i=1}^K w_i y_i}{\sum_{i=1}^K w_i}, \quad w_i = \frac{1}{d_i^p + \epsilon} \)

3. K-Means Clustering (การจัดกลุ่มข้อมูล)

3.1 ทฤษฎีและแนวคิดพื้นฐาน (Theoretical Concepts)

K-Means Clustering จัดเป็น Instance-based Unsupervised Learning (การเรียนรู้แบบไม่มีผู้สอน) เนื่องจากชุดข้อมูลไม่มีการระบุป้ายกำกับคลาส (Unlabeled Data) อัลกอริทึมนี้เป็นแบบ Partitioning ที่ทำการแบ่งชุดข้อมูลออกเป็น \(K\) กลุ่ม โดยอาศัยระยะห่างระหว่างจุดข้อมูลกับ จุดศูนย์กลางของกลุ่ม (Centroid) มีเป้าหมายเพื่อลดผลรวมความแปรปรวนหรือระยะทางกำลังสองภายในกลุ่ม (Within-Cluster Sum of Squares - WCSS / Inertia)

3.2 ขั้นตอนการทำงาน 5 ขั้นตอน (Algorithm Steps)

  1. กำหนดค่า K: ระบุจำนวนกลุ่มที่ต้องการแบ่งล่วงหน้า
  2. กำหนด Initial Centroids: สุ่มหรือระบุตำแหน่งศูนย์กลางเริ่มต้น \(C_1, C_2, \dots, C_K\)
  3. Cluster Assignment: คำนวณระยะห่างระหว่างข้อมูลทุกจุดกับ Centroid แล้วมอบหมายให้สังกัด Centroid ที่ใกล้ที่สุด
  4. Update Centroid: คำนวณจุดศูนย์กลางใหม่จากค่าเฉลี่ยพิกัดของสมาชิกในกลุ่ม: \( C_j = \left( \frac{1}{|S_j|} \sum_{x \in S_j} x, \; \frac{1}{|S_j|} \sum_{y \in S_j} y \right) \)
  5. Iteration: วนทำซ้ำขั้นตอน 3 และ 4 จนตำแหน่ง Centroid ไม่เปลี่ยนแปลง (Convergence)

3.3 ตัวอย่างการคำนวณตามสไลด์ (สไลด์หน้า 8-11): ข้อมูล 2 มิติ จุด A ถึง F

จุด พิกัด ระยะทางถึง \(C_1(2,3)\) ระยะทางถึง \(C_2(9,9)\) สังกัดกลุ่ม (รอบที่ 1)
